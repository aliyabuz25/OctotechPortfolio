# Octotech Azərbaycan

Octotech üçün Azərbaycan dilində hazırlanmış statik veb-sayt.

## Yerli işə salma

Layihə qovluğunda terminal açın və çalışdırın:

```bash
python3 -m http.server 8000
```

Sonra `http://127.0.0.1:8000/` ünvanını açın.

Əsas səhifə `index.html`, əlaqə səhifəsi isə `contact.html` faylıdır.
